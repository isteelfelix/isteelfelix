### 🤖 AI-инструменты

Инфраструктура для работы с AI-агентами:

- **[neon-companion](https://github.com/isteelfelix/neon-companion)** — open-source Unity-клиент для AI-агентов с поддержкой аватаров, чата, терминала и удалённых сессий. Полная parity с Hermes Agent.
- **[TencentDB-Agent-Memory](https://github.com/isteelfelix/TencentDB-Agent-Memory)** — локальная долгосрочная память для AI-агентов, 4 уровня, без внешних API.
- **[hermes-agent](https://github.com/isteelfelix/hermes-agent)** — контрибьючу в open-source AI-агента от Nous Research.
